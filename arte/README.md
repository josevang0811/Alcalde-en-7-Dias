# Arte original

Aquí se guardan los dibujos tal como los entregó el equipo de diseño, antes de pasarlos por las herramientas. El juego no lee esta carpeta.

- `originales/mundo/`: el mundo abierto con sus colores originales. Lo que usa el juego (`juego/AlcaldeDigitalNuevo/data/mundo/`) sale de aquí con `herramientas/recolorear_mundo.py` (paleta profunda, nivel 1.4).

Si diseño cambia o agrega un dibujo del mundo, se guarda aquí y se vuelve a correr el script.
